595/2015 Valtioneuvoston asetus metsätalouden ympäristötuen laskennassa käytettävästä puukuutiometrin keskikantohinnasta

Valtioneuvoston päätöksen mukaisesti säädetään kestävän metsätalouden määräaikaisen rahoituslain 10 §:n (34/2015) nojalla:

### 1 § Puukuutiometrin keskikantohinnat

Metsätalouden ympäristötuen laskennassa käytetään maakuntapohjaisesti määritellyn alueen keskikantohintoja seuraavasti:

| Lapin maakunta | 25,23 €/ha |

| Pohjois-Pohjanmaan maakunta | 26,25 €/ha |

| Kainuun maakunta | 28,30 €/ha |

| Pohjois-Karjalan maakunta | 31,94 €/ha |

| Pohjois-Savon maakunta | 31,95 €/ha |

| Keski-Suomen maakunta | 35,26 €/ha |

| Pirkanmaan maakunta | 37,53 €/ha |

| Etelä-Savon maakunta | 35,89 €/ha |

| Uudenmaan maakunta | 37,20 €/ha |

| Pohjanmaan maakunta | 29,31 €/ha |

| Kaakkois-Suomi, joka koostuuKymenlaakson ja Etelä-Karjalan maakunnista | 36,07 €/ha |

| Etelä- ja Keski-Pohjanmaa, joka koostuu Etelä-Pohjanmaan ja Keski-Pohjanmaan maakunnista | 32,04 €/ha |

| Lounais-Suomi, joka koostuu Varsinais-Suomen ja Satakunnan maakunnista | 36,10 €/ha |

| Häme, joka koostuu Kanta-Hämeen ja Päijät-Hämeen maakunnista | 38,15 €/ha |

### 2 § Voimaantulo

Tämä asetus tulee voimaan 1 päivänä kesäkuuta 2015.

Helsingissä 13 päivänä toukokuuta 2015

Maa- ja metsätalousministeri Petteri Orpo Metsäneuvos Marja Hilska-Aaltonen
