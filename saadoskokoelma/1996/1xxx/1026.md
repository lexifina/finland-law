1026/1996 Työministeriön päätös merionnettomuudessa menetetystä henkilökohtaisesta omaisuudesta työntekijälle tulevan korvauksen perusteista annetun valtioneuvoston päätöksen 1 ja 2 §:ssä tarkoitetuista markkamääristä vuonna 1997

Työministeriö on päättänyt merionnettomuudessa menetetystä henkilökohtaisesta omaisuudesta työntekijälle tulevan korvauksen perusteista 22 päivänä maaliskuuta 1979 annetun valtioneuvoston päätöksen (337/1979) 4 §:n nojalla, sellaisena kuin se on 4 päivänä joulukuuta 1991 annetussa valtioneuvoston päätöksessä (1414/1991):

### 1 §

Merionnettomuudessa menetetystä henkilökohtaisesta omaisuudesta työntekijälle tulevan korvauksen perusteista annetun valtio neuvoston päätöksen 1 §:n 2 momentissa tarkoitetut markkamäärät ovat vuonna 1997 seuraavat:

| | | Sisäliikenne | Rannikko-, itämeren- ja pohjanmereniikenne | Valtameri-liikenne |

| A. | Aluksessa asuva henkilökunta: | | | |

| | 1. Päällikkö, konepäällikkö, yliperämies | 9 100 | 14 550 | 17 300 |

| | 2. Muu henkilökunta | 6 200 | 10 550 | 12 300 |

| B. | Henkilökunta, joka ei asu aluksessa: | | | |

| | 1. Päällikkö | 3 300 | | |

| | 2. Muu henkilökunta | 2 250 | | |

### 2 §

Edellä 1 §:ssä mainitun valtioneuvoston päätöksen 2 §:n 2 momentissa tarkoitettu markkamäärä on vuonna 1997 enintään 15 050 markkaa.

### 3 §

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1997.

Helsingissä 10 päivänä joulukuuta 1996

Työministeri Liisa Jaakonsaari Hallitusneuvos Esa Lonka
