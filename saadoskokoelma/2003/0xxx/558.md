558/2003 Oikeusministeriön asetus käräjäoikeuksien kanslioiden ja istuntopaikkojen sijainnista annetun oikeusministeriön päätöksen 1 §:n muuttamisesta

Oikeusministeriön päätöksen mukaisesti kumotaan käräjäoikeuksien kanslioiden ja istuntopaikkojen sijainnista 16 päivänä syyskuuta 1993 annetun oikeusministeriön päätöksen (821/1993) 1 §:n Alavuden ja Lapuan käräjäoikeuksia koskevat kohdat sekä muutetaan Kauhavan, Seinäjoen ja Äänekosken käräjäoikeutta koskevat kohdat seuraavasti:

### 1 §

Käräjäoikeuksien kansliat ja istuntopaikat sijaitsevat seuraavasti:

| Käräjäoikeus | Kanslia (s = sivukanslia) | Istunnot |

| Kauhava | Kauhava | Kauhava |

| | | Alajärvi |

| | | Lapua |

| Seinäjoki | Seinäjoki | Seinäjoki |

| | | Alavus |

| | | Jalasjärvi |

| Äänekoski | Äänekoski | Äänekoski |

| | | Saarijärvi |

| | | Viitasaari |

Tämä asetus tulee voimaan Äänekosken käräjäoikeuden osalta 1.9.2003 sekä Kauhavan ja Seinäjoen käräjäoikeuksien osalta 1.1.2005.

Toimenpiteisiin asetuksen täytäntöönpanemiseksi saadaan ryhtyä jo ennen sen voimaantuloa.

Helsingissä 18 päivänä kesäkuuta 2003

Oikeusministeri Johannes Koskinen Hallitusneuvos Heikki Liljeroos
