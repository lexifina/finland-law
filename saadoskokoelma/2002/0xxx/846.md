846/2002 Oikeusministeriön asetus käräjäoikeuksien kanslioiden ja istuntopaikkojen sijainnista annetun oikeusministeriön päätöksen 1 §:n muuttamisesta

Oikeusministeriön päätöksen mukaisesti kumotaan käräjäoikeuksien kanslioiden ja istuntopaikkojen sijainnista 16 päivänä syyskuuta 1993 annetun oikeusministeriön päätöksen (821/1993) 1 §:n Pietarsaaren ja Vammalan käräjäoikeuksia koskevat kohdat sekä muutetaan Mustasaaren, Nurmeksen ja Tampereen käräjäoikeuksia koskevat kohdat seuraavasti:

### 1 §

Käräjäoikeuksien kansliat ja istuntopaikat sijaitsevat seuraavasti:

| Käräjäoikeus | Kanslia (s = sivukanslia) | Istunnot |

| - - - - - - - - - - - - - - - - - - - - - |

| Mustasaaren käräjäoikeus | Vaasa | Vaasa |

| | Kristiinankaupunki (s) | Kristiinankaupunki |

| | Pietarsaari (s) | Pietarsaari |

| - - - - - - - - - - - - - - - - - - - - - |

| Nurmeksen käräjäoikeus | Nurmes | Nurmes |

| | | Lieksa |

| - - - - - - - - - - - - - - - - - - - - - |

| Tampereen käräjäoikeus | Tampere | Tampere |

| | Vammala (s 1.6.-31.12.2002) | Mänttä |

| | | Orivesi |

| | | Vammala |

Tämä asetus tulee voimaan Mustasaaren, Nurmeksen ja Pietarsaaren käräjäoikeuksien osalta 1.3.2003 sekä Tampereen ja Vammalan käräjäoikeuksien osalta 1.6.2003.

Toimenpiteisiin asetuksen täytäntöönpanemiseksi saadaan ryhtyä jo ennen sen voimaantuloa.

Helsingissä 3 päivänä lokakuuta 2002

Oikeusministeri Johannes Koskinen Hallitusneuvos Heikki Liljeroos
