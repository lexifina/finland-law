1294/1992 Valtioneuvoston päätös saaristokunnista ja kuntien saaristo-osista

Valtioneuvosto on saariston kehityksen edistämisestä 26 päivänä kesäkuuta 1981 annetun lain (494/81) 9 §:n nojalla sisäasiainministeriön esittelyssä päättänyt:

### 1 §

Saaristokuntia ovat:

| Kuopion lääni | Vehmersalmi |

| Mikkelin lääni | Puumala, Sulkava ja Hirvensalmi |

| | 31.12.1993 saakka |

| Oulun lääni | Hailuoto |

| Pohjois-Karjalan lääni | Rääkkylä 31.12.1993 saakka |

| Turun ja Porin lääni | Dragsfjärd, Houtskari, Iniö, |

| | Korppoo, Kustavi, Nauvo ja Velkua |

| Vaasan lääni | Maksamaa |

### 2 §

Kuntien saaristo-osiksi määrätään seuraavissa kunnissa ilman kiinteää tieyhteyttä olevat saaret sekä kunnan kohdalla erikseen mainitut alueet, joihin on kiinteä tieyhteys:

| Kuopion lääni | Tervo (myös Linnonsaari, |

| | Käpysaari ja Lietniemi) |

| Kymen lääni | Kotka, Pyhtää (myös Munapirtin |

| | saari), Taipalsaari (myös |

| | Kattelus-saari) |

| Mikkelin lääni | Anttola (myös Saukonsalo, |

| | Piekälänsaari, Pihlajasalo ja |

| | Hirvensalo) ja Savonlinna |

| Oulun lääni | Vaala (myös Manamansalo) |

| Pohjois-karjalan lääni | Juuka ja Kesälahti |

| Turun ja Porin lääni | Halikko (myös Angelniemi ja |

| | Angelansaari), Merimasku, |

| | Parainen, Rymättylä, Särkisalo, |

| | Taivassalo ja Piikkiö |

| Uudenmaan lääni | Inkoo (myös Storramsjö, Barö ja |

| | Räfsö), Pernaja (myös Sarvsalö), |

| | Porvoon maalaiskunta, Sipoo |

| | (myös Kitö ja Löparö) ja |

| | Tammisaari |

| Vaasan lääni | Maalahti, Mustasaari |

| | (myös Köklot ja Värlax) |

### 3 §

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1993 ja on voimassa 31. päivään joulukuuta 1993.

Tällä päätöksellä kumotaan saaristokunnista ja kuntien saaristo-osista 5 päivänä syyskuuta 1991 annettu valtioneuvoston päätös (1197/91).

Helsingissä 10 päivänä joulukuuta 1992

Sisäasiainministeri Mauri Pekkarinen Neuvotteleva virkamies Veijo Kavonius
