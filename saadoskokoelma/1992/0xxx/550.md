550/1992 Valtioneuvoston päätös sokerin tuontimaksun väliaikaisesta muuttamisesta

Valtioneuvosto on kustannustason nousun ehkäisemisestä eräissä tapauksissa 5 päivänä huhtikuuta 1974 annetun lain (284/74) 2 §:n 1 momentin nojalla valtiovarainministeriön esittelystä muuttanut sokerin tuontimaksun väliaikaisesti seuraavasti:

| Nimike | Tavara | Tuontimaksu mk |

| 17.01:stä | Muu sokeri kuin vanilja- ja |

| | vanilliinisokeri tullattaessa |

| | aikana 1.8- 30.9.1992 1 kg | 1,85 |

| | Huom. Mikäli sokerin tullaus- |

| | arvo alittaa tason 1,35 |

| | mk/kg, korotetaan tuonti- |

| | maksua alitusta |

| | vastaavalla määrällä. |

Tämä päätös tulee voimaan 1 päivänä elokuuta 1992 ja se on voimassa 30 päivään syyskuuta 1992. Sitä sovelletaan päätöksessä mainittuna aikana tullattuun sokeriin.

Helsingissä 25 päivänä kesäkuuta 1992

Valtiovarainministeri Iiro Viinanen Finanssineuvos Lasse Valtonen
