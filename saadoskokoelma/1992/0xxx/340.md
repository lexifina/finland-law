340/1992 Valtioneuvoston päätös sokerin tuontimaksun väliaikaisesta muuttamisesta

Valtioneuvosto on kustannustason nousun ehkäisemisestä eräissä tapauksissa 5 päivänä huhtikuuta 1974 annetun lain (284/74) 2 §:n 1 momentin nojalla valtiovarainministeriön esittelystä muuttanut sokerin tuontimaksun väliaikaisesti seuraavasti:

| Nimike | Tavara | Tuontimaksu mk |

| 17.01:stä | Muu sokeri kuin vanilja- ja |

| | vanilliinisokeri tullattaessa |

| | aikana 23.4- 31.7.1992 1 kg |

| | Huom. Mikäli sokerin tullausarvo |

| | alittaa tason 1,35 mk/kg, korote- |

| | taan tuontimaksua alitusta |

| | vastaavalla määrällä. | 1,85 |

Tämä päätös tulee voimaan 23 päivänä huhtikuuta 1992 ja se on voimassa 31 päivään heinäkuuta 1992. Sitä sovelletaan päätöksessä mainittuna aikana tullattuun sokeriin.

Helsingissä 15 päivänä huhtikuuta 1992

Ministeri Mauri Pekkarinen Finanssineuvos Lasse Valtonen
