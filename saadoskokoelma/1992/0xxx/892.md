892/1992 Valtioneuvoston päätös sokerin tuontimaksun väliaikaisesta muuttamisesta

Valtioneuvosto on kustannustason nousun ehkäisemisestä eräissä tapauksissa 5 päivänä huhtikuuta 1974 annetun lain (284/74) 2 §:n 1 momentin nojalla valtiovarainministeriön esittelystä muuttanut sokerin tuontimaksun väliaikaisesti seuraavasti:

| Nimike | Tavara | Tuontimaksu |

| | | mk |

| 17.01:stä | Muu sokeri kuin vanilja- ja |

| | vanilliinisokeri tullattaessa |

| | aikana 1.10.1992-30.6.1993 1 kg | 1,74 |

| | Huom. Mikäli sokerin tullausarvo |

| | alittaa tason 1,42 mk/kg, |

| | korotetaan tuontimaksua |

| | alitusta vastaavalla määrällä. |

Tämä päätös tulee voimaan 7 päivänä lokakuuta 1992 ja se on voimassa 30 päivään kesäkuuta 1993. Sitä sovelletaan päätöksessä mainittuna aikana tullattuun sokeriin.

Helsingissä 1 päivänä lokakuuta 1992

Valtiovarainministeri Iiro Viinanen Finanssineuvos Lasse Valtonen
