924/1987 Valtioneuvoston päätös tupakkatuotteista suoritettavasta lisäverosta

Valtioneuvosto on tupakkaverosta 7 päivänä joulukuuta 1979 annetun lain (875/79) 5§:n nojalla valtiovarainministeriön esittelystä päättänyt:

### 1 §

Tupakkatuotteiden vähittäismyyntihinnasta on suoritettava lisäveroa seuraavasti:

| | Tuote- | Lisävero |

| Tuote | ryhmä | % |

| Savukkeet | 1 | 11,42 |

| Sikarit | | |

| - sikarisavukkeet | 2 | 11,42 |

| - muut sikarit | 3 | 0,02 |

| Piippu- ja savuketupakka | 4 | 6,01 |

| Nuuska- ja purutupakka | 5 | 10,00 |

| Savukepaperi, määräkokoon | | |

| leikattu, myös lehtiöinä tai | | |

| hylsyinä, vähittäismyynti- | | |

| muodossa | 6 | 15,00 |

### 2 §

Lisäveroa on suoritettava savukkeista vähintään seuraavat määrät vähennettynä perusveron määrällä:

| -tilavuus alle 3,80 cm 3 | 266 mk/1000 kpl |

| - tilavuus vähintään 3,80 | |

| cm 3 mutta alle 4,10 cm 3 | 284 mk/1000 kpl |

| - tilavuus vähintään 4,10 | |

| cm 3 | 310 mk/1000 kpl |

### 3 §

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1988.

Tällä päätöksellä kumotaan 15 päivänä marraskuuta 1984 annettu valtioneuvoston päätös tupakkatuotteista suoritettavasta lisäverosta (768/84).

Helsingissä 3 päivänä joulukuuta 1987

Ministeri Ilkka Kanerva Finanssineuvos Lasse Valtonen
