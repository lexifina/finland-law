665/1987 Laki makeisverosta annetun lain muuttamisesta

Eduskunnan päätöksen mukaisesti muutetaan makeisverosta 7 päivänä joulukuuta 1979 annetun lain (867/79) liitteenä oleva verotaulukko, sellaisena kuin se on 12 päivänä joulukuuta 1986 annetussa laissa (913/86), näin kuuluvaksi:

| 17.04:stä | Kaakaota sisältämättömät sokerivalmisteet (myös valkosuklaa): | | |

| | – lakritsi- ja arabikumivalmisteet | 1. | 3,50 |

| | – karamellit, rakeet, toffeet, pastillit, purukumit ja muut tähän nimikkeeseen kuuluvat valmisteet (eivät kuitenkaan fondant, tahnat, tahtaat ja niiden kaltaiset välivalmisteet) | 2. | 3,50 |

| 18.06:sta | Suklaa ja muut kaakaota sisältävät ravintovalmisteet: | | |

| | – suklaa ja kaakaota sisältävät makeiset | 3. | 3,50 |

| 21.06:sta | Muualle kuulumattomat ravintovalmisteet: | | |

| | – karamellit, toffeet, pastillit, purukumit ja niihin rinnastettavat makeiset; kuvioiksi, palasiksi tai tangoiksi muodostettu marmelaati | 4. | 3,50 |

| | – arabikumivalmisteet | 5. | 3,50 |

Tämä laki tulee voimaan 1 päivänä tammikuuta 1988.
