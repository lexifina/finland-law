214/1989 Valtiovarainministeriön päätös valtion palveluksessa olevilta perittävistä ateriakorvauksista

Valtiovarainministeriö on valtion palveluksessa olevilta perittävistä ateriakorvauksista 30 päivänä joulukuuta 1985 annetun valtioneuvoston päätöksen (3/86) 2 §:n nojalla päättänyt seuraavaa:

### 1 §

Valtion palveluksessa olevalta, joka osallistuu viraston tai laitoksen järjestämään laitosruokailuun viraston tai laitoksen ylläpitämässä ruokalassa, peritään ateriasta korvaus seuraavasti:

| Ateriakorvaus | mk/ateria |

| - Kouluaterian luonteinen ateria | 11,00-13,85 |

| - Lounas tai päivällinen | 12,80-18,30 |

| - Tavanomaista monipuolisempi pääateria (seisova pöytä tai vastaava) | 16,00-21,10 |

| Väliateriat: |

| - Puuroannos tai vastaava | 3,10-4,00 |

| - Annos kahvia tai teetä, voita ja leipää tai kahvileipää | 5,50-7,60 |

| - Aamiainen tai vastaava | 5,50-9,20 |

| - Annos kahvia tai teetä | 2,10-3,40 |

| | mk/päivä |

| Päiväkorvaus | 30,00-44,20 |

### 2 §

Tämä päätös tulee voimaan 1 päivänä huhtikuuta 1989.

### 3 §

Tällä päätöksellä kumotaan valtion palveluksessa olevilta perittävistä ateriakorvauksista 4 päivänä helmikuuta 1988 annettu valtiovarainministeriön päätös (107/88).

Helsingissä 2 päivänä maaliskuuta 1989

Ministeri Ulla Puolanne Ylitarkastaja Sinikka Wuolijoki
