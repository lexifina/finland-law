295/1989 Valtioneuvoston päätös myytäväksi toimitetun rehusilakan vähimmäishinnoista ja tavoitehinnoista

Valtioneuvosto on 18 päivänä heinäkuuta 1975 annetun kalastustulolain (621/75) 2§:n 3 momentin nojalla, sellaisena kuin se on 23 päivänä joulukuuta 1988 annetussa laissa (1157/88), maa- ja metsätalousministeriön esittelystä päättänyt:

### 1 §

Myytäväksi toimitetun rehusilakan vähimmäishinnat ja tavoitehinnat ovat:

| | vähimmäishinta | tavoitehinta |

| | mk/kg | mk/kg |

| rehusilakka 16.4.-15.7.1989 | | |

| -Vaasan läänissä ja siitä pohjoiseen | 0,45 | 0,95 |

| -muualla | 0,40 | 0,90 |

### 2 §

Tämä päätös tulee voimaan 1 päivänä huhtikuuta 1989.

Helsingissä 22 päivänä maaliskuuta 1989

Ministeri Ole Norrback Toimistopäällikkö Markku Aro
