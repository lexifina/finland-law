926/1989 Valtioneuvoston päätös eräiden hedelmien tullien ja vehnägluteenin tuontimaksun väliaikaisesta muuttamisesta

Valtioneuvosto on kustannustason nousun ehkäisemisestä eräissä tapauksissa 5 päivänä huhtikuuta 1974 annetun lain (284/74) 2§:n 1 momentin nojalla valtiovarainministeriön esittelystä muuttanut alempana mainittuihin tullitariffin nimikkeisiin kuuluvien tavaroiden tullit ja tuontimaksun väliaikaisesti seuraavasti:

| | 8. Ryhmä | |

| | Syötävät hedelmät ja pähkinät; sitrushedelmien ja melonin kuoret | |

| 08.05:sta | Tuoreet tai kuivatut sitrushedelmät: | |

| | A. appelsiinit: | |

| | II:sta, tullattaessa aikana 15.11.-31.12.1989 | 6 % |

| | B. mandariinit (myös tangeriinit ja satsumat); klementiinit, wilkingit ja muut niiden kaltaiset sitrushybridit: | |

| | II:sta, tullattaessa aikana 15.11.-31.12.1989 | 5,1 % |

| | 11. Ryhmä | |

Tämä päätös tulee voimaan 25 päivänä lokakuuta 1989. Sitä sovelletaan edellä olevassa taulukossa mainittuina ajanjaksoina tullattuihin tavaroihin.
