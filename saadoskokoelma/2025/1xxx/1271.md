1271/2025 Valtioneuvoston asetus hyvinvointialueiden rahoituksesta annetun valtioneuvoston asetuksen 2 §:n muuttamisesta

Valtioneuvoston päätöksen mukaisesti muutetaan hyvinvointialueiden rahoituksesta annetun valtioneuvoston asetuksen (1392/2022) 2 §, sellaisena kuin se on asetuksessa 873/2024, seuraavasti:

### 2 § Laskennallisten kustannusten perushinnat

Hyvinvointialueiden rahoituksesta annetun lain 13–20, 20 a ja 21–23 §:ssä tarkoitetut perushinnat ovat vuonna 2026 seuraavat:

| Sosiaali- ja terveydenhuollon laskennallisetkustannukset | euroa |

| Asukasmäärä | 620,73 |

| Terveydenhuolto | 2 106,78 |

| Vanhustenhuolto | 806,89 |

| Sosiaalihuolto | 922,05 |

| Hyvinvoinnin ja terveyden edistäminen | 70,95 |

| Asukastiheys | 70,81 |

| Vieraskielisyys | 871,49 |

| Kaksikielisyys | 530,40 |

| Saaristoisuus | 887,13 |

| Saamenkielisyys | 2 231,37 |

| Yliopistosairaalalisä | 42,39 |

| Pelastustoimen laskennalliset kustannukset | euroa |

| Asukasmäärä | 69,32 |

| Asukastiheys | 5,32 |

| Riskitekijät | 32,01 |

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2026.
