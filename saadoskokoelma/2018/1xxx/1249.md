1249/2018 Maa- ja metsätalousministeriön asetus metsätalouden ympäristötuen laskennassa käytettävästä puukuutiometrin keskikantohinnasta

Maa- ja metsätalousministeriön päätöksen mukaisesti säädetään kestävän metsätalouden määräaikaisen rahoituslain (34/2015) 10 §:n 4 momentin nojalla, sellaisena kuin se on laissa 227/2016:

### 1 § Puukuutiometrin keskikantohinnat

Metsätalouden ympäristötuen laskennassa käytetään maakuntapohjaisesti määritellyn alueen keskikantohintoja seuraavasti:

| Uusimaa | 33,44 € |

| Varsinais-Suomi | 36,60 € |

| Satakunta | 36,05 € |

| Kanta-Häme | 38,16 € |

| Pirkanmaa | 36,51 € |

| Päijät-Häme | 39,18 € |

| Kymenlaakso | 35,37 € |

| Etelä-Karjala | 35,04 € |

| Etelä-Savo | 36,52 € |

| Pohjois-Savo | 31,93 € |

| Pohjois-Karjala | 31,24 € |

| Keski-Suomi | 34,94 € |

| Etelä-Pohjanmaa | 33,45 € |

| Pohjanmaa | 29,22 € |

| Keski-Pohjanmaa | 29,11 € |

| Pohjois-Pohjanmaa | 26,62 € |

| Kainuu | 26,26 € |

| Lappi | 25,57 € |

### 2 § Voimaantulo

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2019.

Helsingissä päivänä 19 joulukuuta 2018

Maa- ja metsätalousministeri Jari Leppä Neuvotteleva virkamies Ville Schildt
