107/1988 Valtiovarainministeriön päätös valtion palveluksessa olevilta perittävistä ateriakorvauksista

Valtiovarainministeriö on valtion palveluksessa olevilta perittävistä ateriakorvauksista 30 päivänä joulukuuta 1985 annetun valtioneuvoston päätöksen (3/86) 2 §:n nojalla päättänyt seuraavaa:

### 1 §

Valtion palveluksessa olevalta, joka osallistuu viraston tai laitoksen järjestämään laitosruokailuun viraston tai laitoksen ylläpitämässä ruokalassa, peritään ateriasta korvaus seuraavasti:

| Ateriakorvaus | mk/ateria |

| - Kouluaterian luonteinen ateria | 8,75-13,05 |

| - Lounas tai päivällinen | 12,05-17,30 |

| - Tavanomaista monipuolisempi pääateria (seisova pöytä tai vastaava) | 14,30-19,90 |

| Väliateriat: | |

| - Puuroannos tai vastaava | 2,90-3,75 |

| - Annos kahvia tai teetä, voita ja leipää tai kahvileipää | 4,85-7,15 |

| - Aamiainen tai vastaava | 4,50-8,70 |

| - Annos kahvia tai teetä | 2,10-3,20 |

| | mk/päivä |

| Päiväkorvaus | 28,00-41,70 |

### 2 §

Tämä päätös tulee voimaan 1 päivänä maaliskuuta 1988.

### 3 §

Tällä päätöksellä kumotaan valtion palveluksessa olevilta perittävistä ateriakorvauksista 29 päivänä tammikuuta 1987 annettu valtiovarainministeriön päätös (VM 8/37/87).

Helsingissä 4 päivänä helmikuuta 1988

Ministeri Ulla Puolanne Ylitarkastaja Sinikka Wuolijoki
