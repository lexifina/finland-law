493/1988 Asetus poliisin eräiden virkojen nimien muuttamisesta

Sisäasiainministerin esittelystä säädetään 24 päivänä lokakuuta 1986 annetun valtion virkamieslain (755/86) 7§:n nojalla:

### 1 §

Muutetaan:

| Lukumäärä | Nykyinen virkanimike | Palkkausluokka | Uusi virkanimike |

| Paikallispoliisi | | | |

| 7 | komisario | A 20 | rikoskomisario |

| 54 | komisario | A 19 | rikoskomisario |

| 31 | ylikonstaapeli | A 16 | rikosylikonstaapeli |

| 87 | ylikonstaapeli | A 15 | rikosylikonstaapeli |

| 267 | vanhempi konstaapeli | A 13 | vanhempi rikoskonstaapeli |

| 108 | vanhempi konstaapeli | A 12 | vanhempi rikoskonstaapeli |

| Keskusrikospoliisi | | | |

| 3 | vanhempi konstaapeli | A 13 | vanhempi rikoskonstaapeli |

### 2 §

Tämä asetus tulee voimaan 1 päivänä elokuuta 1988.

Helsingissä 10 päivänä kesäkuuta 1988

Tasavallan Presidentti Mauno Koivisto Sisäasiainministeri Jarmo Rantanen
