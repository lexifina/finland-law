895/1988 Valtioneuvoston päätös eräiden hedelmien tullien väliaikaisesta muuttamisesta

Valtioneuvosto on kustannustason nousun ehkäisemisestä eräissä tapauksissa 5 päivänä huhtikuuta 1974 annetun lain (284/74) 2§:n 1 momentin nojalla valtiovarainministeriön esittelystä muuttanut alempana mainittuihin tullitariffin nimikkeisiin kuuluvien tavaroiden tullit väliaikaisesti seuraavasti:

| 08.05:sta | Tuoreet tai kuivatut sitrushedelmät: | |

| | A. appelsiinit: | |

| | II:sta, tullattaessa aikana 15.11.-31.12.1988 | 7,7 % |

| | B. mandariinit (myös tangeriinit ja satsumat); klementiinit, wilkingit ja muut niiden kaltaiset sitrushybridit: | |

| | II:sta, tullattaessa aikana 15.11.-31.12.1988 | 5,1 % |

| 08.08:sta | Tuoreet omenat, päärynät ja kvittenit: | |

| | A. omenat: | |

| | II.muut: | |

| | c:stä, tullattaessa aikana 4.-30.11.1988 | 6 % |

| | B. päärynät: | |

Tämä päätös tulee voimaan 31 päivänä lokakuuta 1988. Sitä sovelletaan edellä olevassa taulukossa mainittuina ajanjaksoina tullattuihin tavaroihin.
