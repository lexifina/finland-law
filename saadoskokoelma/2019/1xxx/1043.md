1043/2019 Maa- ja metsätalousministeriön asetus metsätalouden ympäristötuen laskennassa käytettävästä puukuutiometrin keskikantohinnasta

Maa- ja metsätalousministeriön päätöksen mukaisesti säädetään kestävän metsätalouden määräaikaisen rahoituslain (34/2015) 10 §:n 4 momentin nojalla, sellaisena kuin se on laissa 227/2016:

### 1 § Puukuutiometrin keskikantohinnat

Metsätalouden ympäristötuen laskennassa käytetään maakuntapohjaisesti määritellyn alueen keskikantohintoja seuraavasti:

| Uusimaa | 35,55 € |

| Varsinais-Suomi | 38,79 € |

| Satakunta | 37,88 € |

| Kanta-Häme | 40,29 € |

| Pirkanmaa | 38,76 € |

| Päijät-Häme | 41,72 € |

| Kymenlaakso | 37,46 € |

| Etelä-Karjala | 37,03 € |

| Etelä-Savo | 39,11 € |

| Pohjois-Savo | 34,25 € |

| Pohjois-Karjala | 32,38 € |

| Keski-Suomi | 36,81 € |

| Etelä-Pohjanmaa | 34,61 € |

| Pohjanmaa | 30,29 € |

| Keski-Pohjanmaa | 30,51 € |

| Pohjois-Pohjanmaa | 27,72 € |

| Kainuu | 26,24 € |

| Lappi | 27,03 € |

### 2 § Voimaantulo

Tämä asetus tulee voimaan 1 päivänä marraskuuta 2019. Tätä asetusta sovelletaan sellaisiin ympäristötukihakemuksiin, jotka ovat tulleet vireille 1 päivänä marraskuuta 2019 tai sen jälkeen.

Helsingissä 29 päivänä lokakuuta 2019

Maa- ja metsätalousministeri Jari Leppä Neuvotteleva virkamies Ville Schildt
