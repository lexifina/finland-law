633/2005 Oikeusministeriön päätös käräjäoikeuksien kanslioiden ja istuntopaikkojen sijainnista annetun oikeusministeriön päätöksen 1 §:n muuttamisesta

Oikeusministeriön päätöksen mukaisesti kumotaan käräjäoikeuksien kanslioiden ja istuntopaikkojen sijainnista 16 päivänä syyskuuta 1993 annetun oikeusministeriön päätöksen (821/1933) 1 §:n Loimaan ja Nilsiän käräjäoikeutta koskevat kohdat sekä muutetaan Forssan ja Kuopion käräjäoikeutta koskevat kohdat seuraavasti:

### 1 §

| Käräjäoikeus | Kanslia | Istunnot |

| | (s = sivukanslia) | |

| Forssa-Loimaa | Forssa | Forssa |

| | Loimaa (s) | Loimaa |

| Kuopio | Kuopio | Kuopio |

| | Nilsiä (s) | Nilsiä |

| | Suonenjoki (s) | Suonenjoki |

Tämä päätös tulee voimaan 1.1.2006.

Toimenpiteisiin päätöksen täytäntöönpanemiseksi saadaan ryhtyä jo ennen sen voimaantuloa.

Helsingissä 18 päivänä elokuuta 2005

Oikeusministeri Johannes Koskinen Hallitusneuvos Heikki Liljeroos
