972/2005 Valtioneuvoston asetus vuodelta 2005 maksettavasta Etelä-Suomen kansallisesta tuesta annetun valtioneuvoston asetuksen 5 §:n muuttamisesta

Valtioneuvoston päätöksen mukaisesti, joka on tehty maa- ja metsätalousministeriön esittelystä, muutetaan vuodelta 2005 maksettavasta Etelä-Suomen kansallisesta tuesta 20 päivänä tammikuuta 2005 annetun valtioneuvoston asetuksen (12/2005) 5 §:n 3 momentti, sellaisena kuin se on asetuksessa 898/2005, seuraavasti:

### 5 § Eläinyksikköä kohti maksettavat tuet

Tukea myönnetään enintään seuraavasti:

| Tukialueet A ja B | euroa/eläinyksikkö |

| Emolehmät ja emolehmähiehot | 86 |

| Sonnit | 219 |

| Uuhet | 212 |

| Kutut | 212 |

| Hevoset | 214 |

| Siat | |

| Emakot ja karjut | 215 |

| Lihasiat ja nuoret siitossiat | 215 |

| Kanat, mukaan lukien emokanat | 207 |

| Lihasiipikarja | |

| Broilerit ja lihasiipikarjaemot | 196 |

| Muu lihasiipikarja | 196 |

Tämä asetus tulee voimaan 14 päivänä joulukuuta 2005.

Ennen asetuksen voimaantuloa voidaan ryhtyä asetuksen täytäntöönpanon edellyttämiin toimenpiteisiin.

Helsingissä 8 päivänä joulukuuta 2005

Maa- ja metsätalousministeri Juha Korkeaoja Ylitarkastaja Esa Hiiva
