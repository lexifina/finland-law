100/2008 Oikeusministeriön asetus käräjäoikeuksien kanslioiden ja istuntopaikkojen sijainnista annetun oikeusministeriön asetuksen 1 §:n muuttamisesta

Oikeusministeriön päätöksen mukaisesti kumotaan käräjäoikeuksien kanslioiden ja istuntopaikkojen sijainnista 7 päivänä joulukuuta 2006 annetun oikeusministeriön asetuksen (1111/2006) 1 §:n Heinolan, Imatran ja Loviisan käräjäoikeuksia koskevat kohdat sekä muutetaan 1 §:n Lahden, Lappeenrannan ja Porvoon käräjäoikeuksia koskevat kohdat, seuraavasti:

### 1 §

Käräjäoikeuksien kansliat ja istuntopaikat sijaitsevat seuraavasti:

| Käräjäoikeus | Kanslia (s= sivukanslia) | Istuntopaikka |

| Lahti | Lahti | Lahti |

| | Heinola (s) | Heinola |

| | Orimattila (s) | Orimattila |

| - - - - - - - - - - - - - |

| Lappeenranta | Lappeenranta | Lappeenranta |

| | Imatra (s) | Imatra |

| | | Luumäki |

| - - - - - - - - - - - - - |

| Porvoo | Porvoo | Porvoo |

| | Loviisa (s) | Loviisa |

| - - - - - - - - - - - - - |

Tämä asetus tulee voimaan 1 päivänä lokakuuta 2008.

Ennen tämän asetuksen voimaantuloa voidaan ryhtyä asetuksen täytäntöönpanon edellyttämiin toimenpiteisiin.

Helsingissä 7 päivänä helmikuuta 2008
