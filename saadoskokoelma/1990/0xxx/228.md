228/1990 Valtiovarainministeriön päätös valtion palveluksessa olevilta perittävistä ateriakorvauksista

Valtiovarainministeriö on valtion palveluksessa olevilta perittävistä ateriakorvauksista 30 päivänä joulukuuta 1985 annetun valtioneuvoston päätöksen (3/86) 2 §:n nojalla päättänyt seuraavaa:

### 1 §

Valtion palveluksessa olevalta, joka osallistuu viraston tai laitoksen järjestämään laitosruokailuun viraston tai laitoksen ylläpitämässä ruokalassa, peritään ateriasta korvaus seuraavasti:

| Ateriakorvaus | mk/ateria |

| - Kouluaterian luonteinen ateria | 11,50-14,50 |

| - Lounas tai päivällinen | 13,40-19,10 |

| - Tavanomaista monipuolisempi pääateria (seisova pöytä tai vastaava) | 17,00-22,10 |

| Väliateriat: | |

| - Puuroannos tai vastaava | 3,25-4,20 |

| - Annos kahvia tai teetä, voita ja leipää tai kahvileipää | 5,75-7,95 |

| - Aamiainen tai vastaava | 5,75-9,60 |

| - Annos kahvia tai teetä | 2,20-3,55 |

| | mk/päivä |

| Päiväkorvaus | 31,50-46,20 |

### 2 §

Tämä päätös tulee voimaan 1 päivänä huhtikuuta 1990.

### 3 §

Tällä päätöksellä kumotaan valtion palveluksessa olevilta perittävistä ateriakorvauksista 2 päivänä maaliskuuta 1989 annettu valtiovarainministeriön päätös (214/89).

Helsingissä 1 päivänä maaliskuuta 1990

Ministeri Ulla Puolanne Ylitarkastaja Sinikka Wuolijoki
