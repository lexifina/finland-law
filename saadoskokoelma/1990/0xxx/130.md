130/1990 Asetus lihavalmisteasetuksen 24 ja 28 §:n muuttamisesta

Kauppa- ja teollisuusministeriön toimialaan kuuluvia asioita käsittelemään määrätyn ministerin esittelystä muutetaan 28 päivänä lokakuuta 1988 annetun lihavalmisteasetuksen (902/88) 24 ja 28§ näin kuuluviksi:

### 24 §

A- ja B-luokan makkaroiden lihapitoisuuksien tulee olla vähintään seuraavat:

| | A-luokka | B-luokka |

| 1)kestomakkara | 95 % | 95 % |

| 2)leikkelemakkara | 65 % | 50 % |

| 3)ruokamakkara | 60 % | 45 % |

| 4)raakamakkara | 60% | 50% |

### 28 §

Lihan, elimien ja lihaan rinnastettavien ruhonosien lisäksi saa kestomakkaroihin ja leikkelemakkaroihin käyttää muita valmistusaineita, laskettuna painoprosentteina valmiista elintarvikkeesta, seuraavasti:

| Makkararyhmä | Kestomakkarat | Leikkelemakkarat |

| Makkaraluokka | A | B | A | B |

| Lihapitoisuus, vähintään | 95 % | 95 % | 65 % | 50 % |

| Muut valmistusaineet | 1.Kananmunaa tai kananmunavalmistetta | - | - | + | + |

| 2. Maitojauhetta, maitojauhe- tai maitoproteiinivalmistetta, proteiiniksi laskettuna yhteensä enintään | - | - | 1,5 % | + |

| 3. Perunajauhoa, vehnä- tai ohratärkkelystä, tärkkelykseksi laskettuna, yhteensä enintään | - | - | - | 5 % |

| 4.Veriplasmaa tai verta | - | - | + | + |

| 5. Mono- ja disakkarideja, fysikaalisesti muunnettua tärkkelystä tai hydrolysoitua tärkkelystä yhteensä enintään | 1 % | 1 % | 0,5 % | 0,5 % |

| 6.Muita elintarvikkeita | +*) | +*) | +**) | +**) |

| 7.Vettä ja jäätä | - | - | + | + |

+ Käyttö vapaa.

- Ei saa käyttää.

*) Kestomakkaraan vain sipulia, tomaattia, paprikaa ja juustoa.

**) Mausteenomaisesti sekä makkaran ulkonäköön, mutta ei sidonta-aineena makkaramassan rakenteeseen vaikuttavasti.

Tämä asetus tulee voimaan 1 päivänä maaliskuuta 1990.

Helsingissä 9 päivänä helmikuuta 1990

Tasavallan Presidentti Mauno Koivisto Ministeri Pertti Salolainen
