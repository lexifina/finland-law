518/1990 Asetus kasvintarkastuksesta perittävistä maksuista annetun asetuksen 2§:n muuttamisesta

Maa- ja metsätalousministerin esittelystä lisätään kasvintarkastuksesta perittävistä maksuista 23 päivänä joulukuuta 1987 annetun asetuksen (1134/87) 2§:n 1 momenttiin tullitariffin nimikkeen 07.09 ja sen alanimikkeiden jälkeen uusi nimike 07.11 alanimikkeineen sekä nimikkeen 44.03 jälkeen uusi nimike 44.07 alanimikkeineen seuraavasti:

### 2 §

Kasvien ja kasvinosien maahan tuonnin yhteydessä suoritetusta kasvintarkastuksesta peritään jokaisesta erikseen tullattavaksi ilmoitetusta tavaraerästä maksu seuraavasti:

| | 90.00:stä | -muut kasvikset: | |

| | | multaiset tai multaisessa liuoksessa olevat kuorimattomat ja pesemättömät perunat ja muut juurekset | 4,30 |

| 44.07 | | Puu, sahattu tai veistetty (chipped) pituussuunnassa, tasoleikattu tai viiluksi sorvattu, myös höylätty, hiottu tai sormijatkettu, paksuus yli 6 mm: | |
