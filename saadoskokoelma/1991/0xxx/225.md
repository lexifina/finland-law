225/1991 Valtiovarainministeriön päätös valtion palveluksessa olevilta perittävistä ateriakorvauksista

Valtiovarainministeriö on valtion palveluksessa olevilta perittävistä ateriakorvauksista 30 päivänä joulukuuta 1985 annetun valtioneuvoston päätöksen (3/86) 2 §:n nojalla päättänyt seuraavaa:

### 1 §

Valtion palveluksessa olevalta, joka osallistuu viraston tai laitoksen järjestämään laitosruokailuun viraston tai laitoksen ylläpitämässä ruokalassa, peritään ateriasta korvaus seuraavasti:

| Ateriakorvaus | mk/ateria |

| -Kouluaterian luonteinen ate- |

| ria | 12,75-15,50 |

| -Lounas tai päivällinen | 14,50-20,50 |

| -Tavanomaista monipuoli- |

| sempi pääateria (seisova |

| pöytä tai vastaava) | 18,20-24,00 |

| Väliateriat: |

| -Puuroannos tai vastaava | 3,50-4,50 |

| -Annos kahvia tai teetä, voita |

| ja leipää tai kahvileipää | 6,15-8,50 |

| -Aamiainen tai vastaava | 6,15-10,30 |

| -Annos kahvia tai teetä | 2,35-3,80 |

| | mk/päivä |

| Päiväkorvaus | 34,00-50,00 |

### 2 §

Tämä päätös tulee voimaan 1 päivänä maaliskuuta 1991.

### 3 §

Tällä päätöksellä kumotaan valtion palveluksessa olevilta perittävistä ateriakorvauksista 1 päivänä maaliskuuta 1990 annettu valtiovarainministeriön päätös (228/90).

Helsingissä 6 päivänä helmikuuta 1991

Ministeri Ulla Puolanne Ylitarkastaja Sinikka Wuolijoki
