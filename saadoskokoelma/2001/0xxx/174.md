174/2001 Maa- ja metsätalousministeriön ilmoitus eräistä ministeriön asetuksista

Maa- ja metsätalousministeriö ilmoittaa Suomen säädöskokoelmasta 25 päivänä helmikuuta 2000 annetun lain (188/2000) 4 §:n nojalla: Maa- ja metsätalousministeriö on antanut seuraavat asetukset:

| Asetuksen nimi | | n:o | antopäivä | voimaantulo |

| MMM:n asetus bakteriologisesta tutkimuksesta lihantarkastuksessa annetun maa- ja metsätalousministeriön päätöksen muuttamisesta | | 5/EEO/2001 | 16.2.2001 | 1.3.2001 |

| MMM:n asetus keittokokeen suorittamisesta ja lihan pH:n mittaamisesta annetun maa- ja metsätalousministeriön päätöksen muuttamisesta | | 6/EEO/2001 | 16.2.2001 | 1.3.2001 |

| MMM:n asetus trikiinitutkimuksesta annetun maa- ja metsätalousministeriön yleiskirjeen muuttamisesta | | 7/EEO/2001 | 16.2.2001 | 1.3.2001 |

| MMM:n asetus linnunmunien hygieniavaatimuksista annetun maa- ja metsätalousministeriön päätöksen muuttamisesta | | 8/EEO/2001 | 16.2.2001 | 1.3.2001 |

| MMM:n asetus tarhatun riistan ja kanin lihahygieniasta annetun maa- ja metsätalousministeriön päätöksen muuttamisesta | | 9/EEO/2001 | 16.2.2001 | 1.3.2001 |

| MMM:n asetus siipikarjan lihahygieniasta annetun maa- ja metsätalousministeriön päätöksen muuttamisesta | | 10/EEO/2001 | 16.2.2001 | 1.3.2001 |

| MMM:n asetus eräiden maa- ja metsätalousministeriön päätösten ja asetusten muuttamisesta | | 11/EEO/2001 | 20.2.2001 | 1.3.2001 |

Edellä mainitut asetukset on julkaistu maa- ja metsätalousministeriön eläinlääkintä- ja elintarvikeosaston määräyskokoelmassa. Asetukset ovat saatavissa maa- ja metsätalousministeriön eläinlääkintä- ja elintarvikeosastosta, osoite Kluuvikatu 4 A, 00100 Helsinki, puhelin (09)1601.

Helsingissä 22 päivänä helmikuuta 2001
