1565/2001 Kauppa- ja teollisuusministeriön asetus Kuluttajaviraston maksullisista suoritteista annetun kauppa- ja teollisuusministeriön asetuksen liitteenä olevan maksutaulukon muuttamisesta

Kauppa- ja teollisuusministeriö on muuttanut Kuluttajaviraston maksullisista suoritteista 28 päivänä helmikuuta 2001 annetun kauppa- ja teollisuusministeriön asetuksen (197/2001) liitteenä olevan maksutaulukon seuraavasti:

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2002.

Helsingissä 19 päivänä joulukuuta 2001

Ministeri Kimmo Sasi Ylitarkastaja Ulla Karhu

Liite

Maksutaulukko

Kuluttajaviraston julkisoikeudelliset suoritteet

Hakemuksesta tehdyt päätökset ovat maksullisia myös silloin, kun hakemus hylätään. Maksut eivät sisällä laskutuksesta aiheutuvia kustannuksia, jotka peritään erikseen. Maksut ovat seuraavat:

| 1) valmismatkaliikkeen harjoittajan rekisteröintiä koskeva päätös | | 277,51 € |

| 2) vakuuden vuotuinen valvontamaksu | | 218,64 €/vuosi |

| 3) tuoteturvallisuuslain (914/1986) 24 §:n 4 momentissa tarkoitettu poikkeuslupa | | 622,30 € |

| 4) kosmeettisen valmisteen valmistajan, valmistuttajan tai maahantuojan rekisteröintiä koskeva päätös | | 84,09 € |

| 5) kosmeettisen valmisteen valmistajan, valmistuttajan tai maahantuojan rekisteröintiä koskevan ilmoituksen muutosta koskeva päätös | | 33,64 € |

| 6) ote valmismatkaliikerekisteristä | | 10,09 € |

Kohdassa 2 mainittua vakuuden vuotuista valvontamaksua ei peritä ensimmäiseltä rekisteröintivuodelta.
