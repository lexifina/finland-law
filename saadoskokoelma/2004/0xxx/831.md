831/2004 Ympäristöministeriön asetus Suomen ympäristökeskuksen maksullisista suoritteista annetun asetuksen liitteen 5 §:n muuttamisesta

Ympäristöministeriön päätöksen mukaisesti muutetaan Suomen ympäristökeskuksen maksullisista suoritteista 17 päivänä joulukuuta 2003 annetun asetuksen (1240/2003) liitteen 5 § seuraavasti:

### 5 § Muut suoritteet

| Julkisen valvonnan alaisista vesitutkimuslaitoksista annetun asetuksen (325/1962) mukaiset suoritteet |

| - vesitutkimuslaitokseksi hyväksymishakemuksen käsittely | 1 100 |

| - vesitutkimuslaitoksen pätevyyden varmistamiseksi tehtävät tarkastukset | 770 |

| Lisäksi veloitetaan hyväksymishakemuksen käsittelystä ja vesitutkimuslaitoksen tarkastuksesta aiheutuvat matkakustannukset valtion virka- ja työehtosopimuksen mukaisesti. |

| Todistukset, otteet ja jäljennökset | |

| - diaari- ja rekisteriote | 17 |

| - jäljennökset asiakirjoista | |

| - 1-10 sivua samasta asiakirjasta | 0,70/sivu |

| - 11-99 sivua samasta asiakirjasta | 0,35/sivu |

| - yli 100 sivua samasta asiakirjasta | 0,20/sivu |

| - asiakirjan oikeaksi todistaminen | 3,90/asiakirja |

| - toimitusmaksu | 3,90/lähetys |

Tämä asetus tulee voimaan 1 päivänä syyskuuta 2004.

Helsingissä 30 päivänä elokuuta 2004

Ympäristöministeri Jan-Erik Enestam Lainsäädäntöneuvos Jukka Nurmio
