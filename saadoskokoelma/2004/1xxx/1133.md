1133/2004 Oikeusministeriön asetus käräjäoikeuksien kanslioiden ja istuntopaikkojen sijainnista annetun oikeusministeriön päätöksen 1 §:n muuttamisesta

Oikeusministeriön päätöksen mukaisesti muutetaan käräjäoikeuksien kanslioiden ja istuntopaikkojen sijainnista 16 päivänä syyskuuta 1993 annetun oikeusministeriön päätöksen (821/1993) 1 §:n Kauhavan käräjäoikeutta koskeva kohta sellaisena kuin se on oikeusministeriön asetuksessa 558/2003 sekä Oulun käräjäoikeutta koskeva kohta seuraavasti:

### 1 §

Käräjäoikeuksien kansliat ja istuntopaikat sijaitsevat seuraavasti:

| Käräjäoikeus | Kanslia (s = sivukanslia) | Istunnot |

| Kauhava | Kauhava | Kauhava |

| | Lapua (s) 31.3.2006 saakka | Lapua |

| | | Alajärvi |

| - - - - - - - - - - - - - - - - - - |

| Oulu | Oulu | Oulu |

| | | Muhos |

| | | Pudasjärvi |

| | | Pulkkila |

Tämä asetus tulee voimaan Kauhavan käräjäoikeuden osalta 1.1.2005 sekä Oulun käräjäoikeuden osalta 1.3.2005.

Helsingissä 15 päivänä joulukuuta 2004
