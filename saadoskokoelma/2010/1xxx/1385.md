1385/2010 Oikeusministeriön asetus käräjäoikeuksien kanslioiden ja istuntopaikkojen sijainnista annetun oikeusministeriön asetuksen 1 §:n muuttamisesta

Oikeusministeriön päätöksen mukaisesti muutetaan käräjäoikeuksien kanslioiden ja istuntopaikkojen sijainnista annetun oikeusministeriön asetuksen 1 §:n Etelä-Savon käräjäoikeutta koskeva kohta, sellaisena kuin se on asetuksessa 1776/2009, seuraavasti:

### 1 §

Käräjäoikeuksien kansliat ja istuntopaikat sijaitsevat seuraavasti:

| Käräjäoikeus | Kanslia | Istuntopaikka |

| --------------------------------------------- |

| Etelä-Savon käräjäoikeus | Mikkeli | Mikkeli |

| | Savonlinna | Pieksämäki |

| | | Savonlinna |

| --------------------------------------------- |

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2011.

Ennen asetuksen voimaantuloa voidaan ryhtyä asetuksen täytäntöönpanon edellyttämiin toimenpiteisiin.

Helsingissä 28 päivänä joulukuuta 2010

Oikeusministeri Tuija Brax Hallitusneuvos Heikki Liljeroos
