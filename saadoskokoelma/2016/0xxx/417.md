417/2016 Valtioneuvoston asetus Ahvenanmaan maakunnassa sijaitseville kunnille maatalouden tukien toimeenpanotehtävien hoitamisesta vuosilta 2014—2015 suoritettavista korvauksista

Valtioneuvoston päätöksen mukaisesti säädetään maatalouden tukien toimeenpanosta annetun lain (192/2013) 52 §:n nojalla:

### 1 §

Ahvenanmaan maakunnassa sijaitseville kunnille suoritetaan korvausta maatalouden tukien toimeenpanosta annetussa laissa (192/2013) tarkoitettujen tehtävien hoitamisesta vuosilta 2014—2015 aiheutuneista menoista seuraavasti:

| | 2014euro | 2015euro |

| Brändön kunta | 720 | 732 |

| Eckerön kunta | 1225 | 1563 |

| Finströmin kunta | 9727 | 8516 |

| Föglön kunta | 2558 | 2628 |

| Getan kunta | 3062 | 3160 |

| Hammarlandin kunta | 4972 | 5156 |

| Jomalan kunta | 8789 | 9048 |

| Kumlingen kunta | 1296 | 1297 |

| Kökarin kunta | 864 | 865 |

| Lemlandin kunta | 2269 | 1997 |

| Lumparlandin kunta | 1658 | 1597 |

| Maarianhaminan kaupunki | 73 | 67 |

| Saltvikin kunta | 4972 | 5688 |

| Sottungan kunta | 1080 | 998 |

| Sundin kunta | 4250 | 4126 |

| Vårdön kunta | 2485 | 2562 |

### 2 §

Tämä asetus tulee voimaan 8 päivänä kesäkuuta 2016.

Helsingissä 2 päivänä kesäkuuta 2016

Maatalous- ja ympäristöministeri Kimmo Tiilikainen Hallitussihteeri Kyösti Helin
