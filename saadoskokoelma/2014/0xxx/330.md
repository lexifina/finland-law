330/2014 Valtioneuvoston asetus Ahvenanmaan maakunnassa oleville kunnille maatalouden tukien toimeenpanotehtävien hoitamisesta vuosilta 2012—2013 suoritettavista korvauksista

Valtioneuvoston päätöksen mukaisesti säädetään maatalouden tukien toimeenpanosta annetun lain (192/2013) 52 §:n nojalla:

### 1 §

Ahvenanmaan maakunnassa sijaitseville kunnille suoritetaan korvausta maatalouden tukien toimeenpanosta annetussa laissa (192/2013) tarkoitettujen tehtävien hoitamisesta vuosilta 2012—2013 aiheutuneista menoista seuraavasti:

| | 2012 euro | 2013 euro |

| Brändön kunta | 649 | 743 |

| Eckerön kunta | 1485 | 1328 |

| Finströmin kunta | 8972 | 9370 |

| Föglön kunta | 2413 | 2377 |

| Getan kunta | 2970 | 3146 |

| Hammarlandin kunta | 5569 | 5209 |

| Jomalan kunta | 9467 | 8916 |

| Kumlingen kunta | 1175 | 1293 |

| Kökarin kunta | 804 | 839 |

| Lemlandin kunta | 2475 | 2517 |

| Lumparlandin kunta | 1701 | 1713 |

| Maarianhaminan kaupunki | 61 | 69 |

| Saltvikin kunta | 4702 | 4720 |

| Sottungan kunta | 1144 | 1188 |

| Sundin kunta | 4115 | 4125 |

| Vårdön kunta | 2298 | 2447 |

### 2 §

Tämä asetus tulee voimaan 24 päivänä huhtikuuta 2014.

Helsingissä 17 päivänä huhtikuuta 2014

Maa- ja metsätalousministeri Jari Koskinen Hallitussihteeri Kyösti Helin
