79/1997 Oikeusministeriön päätös käräjäoikeuksien kanslioiden ja istuntopaikkojen sijainnista annetun oikeusministeriönpäätöksen 1 §:n muuttamisesta

Oikeusministeriö on muuttanut käräjäoikeuksien kanslioiden ja istuntopaikkojen sijainnista 16 päivänä syyskuuta 1993 annetun oikeusministeriön päätöksen (821/1993) 1 §:n, sellaisena kuin se on osaksi päätöksissä 1145 ja 1292/1995, Heinolan, Joensuun, Jämsän ja Savonlinnan käräjäoikeuksien osalta seuraavasti:

### 1 §

Käräjäoikeuksien kansliat ja istuntopaikat sijaitsevat seuraavasti:

| Käräjäoikeus | Kanslia (s=sivukanslia) | Istunnot |

| Heinola | Heinola | Heinola |

| | | Mäntyharju |

| Joensuu | Joensuu | Joensuu |

| | | Ilomantsi |

| | | Kitee |

| | | Outokumpu |

| | | Tohmajärvi |

| Jämsä | Jämsä | Jämsä |

| Savonlinna | Savonlinna | Savonlinna |

| | | Heinävesi |

### 2 §

Tämä päätös tulee voimaan 1 päivänä maaliskuuta 1997.

Helsingissä 24 päivänä tammikuuta 1997
