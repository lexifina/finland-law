446/1997 Maa- ja metsätalousministeriön päätös metsänviljelyaineiston kaupasta annetun maa- ja metsätalousministeriön päätöksen muuttamisesta

Maa- ja metsätalousministeriö on metsänviljelyaineiston kaupasta 24 päivänä elokuuta 1979 annetun lain (684/1979) 2 §:n nojalla päättänyt lisätä metsänviljelyaineiston kaupasta 23 päivänä joulukuuta 1992 antamansa päätöksen (1533/1992 )13 §:n 1 momentin 2) kohdassa tarkoitettuun liitteseen uuden 4. kohdan seuraavasti:

Liite

Taimien kokovaatimukset

4. Männyn paakkutaimet Oulun ja Lapin läänien alueella

Poiketen siitä, mitä kohdassa 3. määrätään, saadaan Oulun ja Lapin läänien alueella markkinoida sellaisia männyn paakkutaimia, joiden tilavuus on vähintään 15 cm 3 ja kasvatustiheys enintään 3 000 paakkua/m 2.

Taimien koon tulee tällöin täyttää seuraavat vaatimukset:

| MÄNTY | | Taimierän mediaanipituus, cm |

| Kasvatustiheys, paakkua/m 2 | Enimmäismediaanipituus, cm | –8 | 9–10 | 11 | 12 |

| | | Taimen vähimmäispituus erässä, cm |

| 1 601–2 000 | 12 | 3 | 4 | 4 | 5 |

| 2 001–2 500 | 10 | 3 | 4 | | |

| 2 501–3 000 | 8 | 3 | | | |

Tämä päätös tulee voimaan 1 päivänä kesäkuuta 1997.

Helsingissä 22 päivänä toukokuuta 1997

Maa- ja metsätalousministeri Kalevi Hemilä Ylitarkastaja Hannu Kukkonen
